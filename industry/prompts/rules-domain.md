
【HR / FDE / 职位变化领域翻译规则 — 本平台聚焦 HR、FDE 与岗位变化，严格遵守】

1. 歧义默认值：以下词在中文有非 HR/FDE 歧义，**按本平台语境翻译**：
   - HR = 人力资源（指职能或行业时可保留 HR；指部门时写“人力资源部”）
   - FDE = Forward Deployed Engineer，保留英文 FDE；首次出现可写“前线部署工程师（FDE）”
   - Forward Deployed = 前线部署 / 驻客户现场交付；**绝不译“向前部署”**
   - HRBP = HRBP（保留英文，可加“人力资源业务伙伴”）
   - CHRO = 首席人力资源官（CHRO）；CPO = 首席人才官 / 首席人力官（按原文语境，保留 CPO）
   - HRIS = 人力资源信息系统（HRIS）；HCM = 人力资本管理（HCM）；ATS = 招聘管理系统（ATS）
   - EOR = 名义雇主（EOR）；PEO = 专业雇主组织（PEO）
   - Layoff = 裁员；hiring freeze = 招聘冻结；restructuring = 重组；attrition = 自然流失；turnover = 流失率
   - Headcount = 编制 / 员工人数；workforce = 员工队伍 / 劳动力；talent acquisition = 人才招聘
   - Total rewards = 全面薪酬；benefits = 福利；payroll = 薪酬发放 / 工资单；compensation = 薪酬
   - Employee experience = 员工体验；engagement = 敬业度；performance review = 绩效评估；OKR = 保留英文
   - Global employment = 全球用工；contractor = 合同工 / 承包商；full-time equivalent（FTE）= 全职当量（FTE）
   - Requisition = 招聘需求；time-to-hire = 招聘周期；offer acceptance rate = offer 接受率
   - Retention = 留任率；internal mobility = 内部流动；succession planning = 继任计划
   - Upskilling = 技能提升；reskilling = 技能重塑；career change = 职业转型
   - DEI = 保留英文；employee resource group（ERG）= 员工资源小组（ERG）
   - AI 在 HR 场景中 = 保留 AI；不要把所有 HR 科技都写成“AI 产品”
